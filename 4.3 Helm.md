# Helm

Helm es un gestor de paquetes para Kubernetes.

Su función es instalar, configurar y gestionar aplicaciones dentro de Kubernetes de forma sencilla.

Proyecto graduado de la CNCF

## Helm Chart

Un Helm Chart es un paquete que contiene todos los archivos necesarios para desplegar una aplicación en Kubernetes.

Un chart incluye:

- Plantillas YAML
- Configuración
- Metadatos
- Valores configurables

¿Cómo funciona?

- Los desarrolladores crean Helm charts para empaquetar aplicaciones de Kubernetes.
- Los usuarios instalan el Helm charts en su clúster de Kubernetes mediante `helm install`.
- Los usuarios pueden administrar las aplicaciones de Kubernetes mediante `helm upgrade` y `helm rollback`.

## Ejemplo

- Agregar un repositorio (chart repo)

```sh
helm repo add bitnami https://charts.bitnami.com/bitnami
```

- Luego actualizas la lista:

```sh
helm repo update
```
- Instalar un chart en el cluster

```sh
helm install mi-nginx bitnami/nginx
```

- Verificar que se desplegó

```sh
helm list
kubectl get pods
```

- Personalizar el despliegue (values)

```sh
helm install mi-nginx bitnami/nginx \
  --set service.type=NodePort \
  --set replicaCount=2
```

- Usar un archivo values.yaml

values.yaml
```yaml
replicaCount: 2

service:
  type: NodePort
```

```sh
helm install mi-nginx bitnami/nginx -f values.yaml
```

- Eliminar el deployment
  
```sh
helm uninstall mi-nginx
```
