# Observabilidad

La observabilidad (observability) es la capacidad de entender qué está pasando dentro de un sistema complejo analizando sus datos externos, sin tener que mirar directamente su código o estado interno.

En sistemas modernos como microservicios o plataformas de Kubernetes, la observabilidad permite detectar problemas, diagnosticar fallos y entender el comportamiento del sistema en tiempo real.

Los 3 pilares de la observabilidad:

- **Métricas:** Son valores numéricos medidos a lo largo del tiempo.

  Herramientas comunes:
  - Prometheus: Es un sistema de monitorización y alerta de código abierto, diseñado para entornos nativos de la nube y microservicios. 
  - Grafana: Es una plataforma de código abierto líder para la visualización y análisis de datos en tiempo real.

- **Logs:** Son registros de eventos que ocurren en el sistema.

  Herramientas comunes:
  - Elasticsearch: Es un motor de búsqueda y analítica distribuido, de código abierto y basado en Apache Lucene, diseñado para almacenar, buscar y analizar grandes volúmenes de datos rápidamente en tiempo real. 
  - Fluentd: Es un recopilador de datos de código abierto, parte de la CNCF, diseñado para unificar la gestión de registros (logs).
  - Loki: Es un sistema de agregación de registros (logs) de alto rendimiento, escalable y rentable.

- **Trazas (Traces):** Permiten seguir el recorrido de una solicitud a través de múltiples servicios.

  Herramientas comunes:
  - Jaeger: Es una plataforma de código abierto para el rastreo distribuido (distributed tracing) en Kubernetes, diseñada para monitorear, depurar y optimizar aplicaciones complejas basadas en microservicios.
  - Zipkin: Es un sistema de rastreo distribuido de código abierto que se ejecuta como contenedor para monitorizar, depurar y solucionar problemas de latencia en aplicaciones de microservicios. 
  - OpenTelemetry: OpenTelemetry (OTel) es un marco de trabajo (framework) de código abierto, estandarizado y neutral, diseñado para recopilar, generar y exportar datos de telemetría (métricas, registros y trazas) de aplicaciones nativas de la nube.

## Gestión de costes en Kubernetes

Se refiere a la optimización de costos en recursos en la nube.

- Optimización de recursos: utilice recursos del tamaño adecuado, por ejemplo, CPU, memoria.
- Autoescalado: ajuste dinámico de la capacidad de los recursos.
- Asignación de costos: distribuya los costos entre equipos, proyectos o departamentos para fines de rendición de cuentas y presupuestación.
- Etiquetado de recursos: para realizar un seguimiento y asignar los costos con precisión.

### Herramientas

- AWS Cost explorer
- Azure Cost Management
- Google Cloud Billing
- Kubecost
- OpenCost
