# Helm

Helm es un gestor de paquetes para Kubernetes.

Su función es instalar, configurar y gestionar aplicaciones dentro de Kubernetes de forma sencilla.

Proyecto graduado de la CNCF

## Helm Chart

Un Helm Chart es un paquete que contiene todos los archivos necesarios para desplegar una aplicación en Kubernetes.

Un chart incluye:

- Plantillas YAML
- Configuración
- Metadatos
- Valores configurables

¿Cómo funciona?

- Los desarrolladores crean Helm charts para empaquetar aplicaciones de Kubernetes.
- Los usuarios instalan el Helm charts en su clúster de Kubernetes mediante `helm install`.
- Los usuarios pueden administrar las aplicaciones de Kubernetes mediante `helm upgrade` y `helm rollback`.
