# Instalacion

## Instalacion en Linux (Minikube)

1. Instalacion de Docker: https://docs.docker.com/engine/install/ubuntu/
2. Agregar al usuario al grupo de usuarios de Docker, luergo reiniciar la terminal
```
sudo usermod -aG docker $USER
```
3. Instalacion Minikube: https://minikube.sigs.k8s.io/docs/start/
4. Instalacion Kubectl: https://kubernetes.io/docs/tasks/tools/install-kubectl-linux/
